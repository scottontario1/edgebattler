# White Fang Clans: design reference

Supplied source art (pixel-style, transparent background) for the White Fang Clans units in `FACTIONS.md` section 5. Never edited; the prep script (`tools/assets/prep_sprites.py`) trims and scales copies into `public/sprites/` when these become runtime sprites. Until then the White Fang classes use a tinted base sprite (see `docs/CULTURE_HOOKS.md`).

| file | unit | notes |
|---|---|---|
| `reaver_sprite.png` | White Fang Reaver | wolf-pelt cloak over riveted plate, fang trophies, bearded axe, forward-leaning stance |
| `berserker_sprite.png` | Berserker | bare-chested scarred veteran, crimson war paint, fang necklace, torn fur kilt, great axe |
| `axeguard_sprite.png` | Axeguard | full iron plate with fur trim, nasal helm, round wolf-emblem shield, grinning, braced stance |
| `fang_hunter_sprite.png` | Fang Hunter | archer in fur and leather, antler-and-bone bow with fang charms, wolf-skull shoulder guard |

Style notes for the rest of the faction: iron-grey plate, off-white wolf fur, bone and fang trophies, brown leather wraps, crimson accents only on the Berserker; strong forward-leaning silhouettes; pixel-art outline weight as in these four.
